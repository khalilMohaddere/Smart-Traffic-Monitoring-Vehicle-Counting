# Smart-Traffic-Monitoring-Vehicle-Counting
traffic monitoring system built with PyTorch, Faster R-CNN, SAHI, and OpenCV to detect, identify, and count vehicles in images and videos. The project uses Slicing Aided Hyper Inference (SAHI) to improve object detection accuracy, especially for small and distant vehicles, enabling more efficient traffic analysis using computer vision.
